# Parameterized Wing Modeling Tool based on CATIA VBA
# CATIA 机翼参数化曲面生成插件
基于 CATIA VBA 二次开发的参数化机翼建模工具，通过输入核心气动参数，自动生成高精度机翼曲面，并内置完整的参数验证体系，可一键校验建模精度。支持闭合与开放翼型文件，兼容主流 `.dat` 格式翼型数据。 

![插件界面](/image/机翼参数化插件.png)

## ✨ 功能特性
- **全参数化驱动**：弦长、梢根比、翼展、后掠角、安装角、扭转角、上反角全部参数化，修改参数即可重新生成
- **翼型智能适配**：自动识别闭合/开放翼型，分别适配后缘点计算逻辑，兼容 Selig 格式 `.dat` 翼型文件
- **精准几何定义**：
  - 自动识别翼型前缘点（x 坐标最小值点）作为定位基准，而非默认坐标原点
  - 自动校准翼弦方向，保证弦长、安装角定义严格符合航空工程标准
  - 严格遵循 1/4 弦线后掠角、几何扭转角、上反角的行业定义
- **自动参数验证**：
  - 自动生成共面基准线，支持 CATIA 测量工具直接读取角度
  - 弹窗输出理论值与实际值对比，一键校验所有参数精度
- **规范建模习惯**：
  - 特征树分层管理，核心几何与验证元素分离
  - 辅助控制点、验证线自动隐藏，视图整洁干净
  - 生成完成自动锁定机翼曲面集为工作对象，符合 CATIA 建模流程

## 🖥️ 环境要求
- 操作系统：Windows  10 / 11
- 软件环境：CATIA V5 R19 及以上版本（支持 VBA 宏）
- 权限要求：CATIA 宏安全级别设置为中或低，允许运行 VBA 宏

## 🚀 安装与使用
### 1. 导入宏文件
1. 下载项目 `wing.catvba` 文件（注意记住安装路径）
2. 打开CATIA→ALT+F8→宏库→VBA项目→添加现有库
3. 添加 `wing.catvba` 
### 2. 运行插件
1. 打开 CATIA，新建或打开一个 Part 文档
2. 按 `Alt+F8` 调出宏窗口，选择对应宏库
3. 运行，弹出参数化操作界面
### 3. 操作步骤
1. 在界面中输入机翼设计参数
2. 点击「翼根文件」「翼尖文件」按钮，分别选择 `.dat` 格式的翼型坐标文件
3. 点击「生成机翼曲面」，等待程序自动完成建模
4. 生成完成后，弹窗显示参数验证结果，可在特征树中查看所有几何元素

## 📋 参数说明

| 参数名称 | 单位 | 说明 |
| :------- | :--- | :--- |
| 翼根弦长 | mm | 机翼根部的弦长尺寸 |
| 梢根比 | - | 翼梢弦长与翼根弦长的比值，取值范围 0~1 |
| 翼展 | mm | 机翼总展长，程序自动生成半翼展模型 |
| 1/4 弦线后掠角 | ° | 机翼 1/4 弦点连线与展向 Z 轴的夹角，正值为后掠 |
| 安装角 | ° | 翼根翼弦与机身轴线的夹角，正值前缘向上 |
| 几何扭转角 | ° | 翼梢相对于翼根的安装角差值，正值为外洗扭转 |
| 上反角 | ° | 机翼前缘线相对于水平面的夹角，正值为上反 |
| 翼根/翼尖翼型文件 | - | 标准 `.dat` 格式翼型坐标文件，支持闭合与开放翼型 |

## 📐 参数验证功能
程序内置完整的参数校验体系，生成后自动在「参数验证辅助线」几何集中创建测量基准元素（默认隐藏，可在特征树中右键手动显示）。

### 角度直接测量
- **1/4 弦后掠角**：选中 `1/4弦线XZ投影` 与 `后掠角展向基准线`，使用 CATIA 角度测量工具直接读取
- **上反角**：选中 `前缘线YZ投影` 与 `上反角水平基准线`，直接测量平面内夹角

### 全参数对比弹窗
生成完成自动弹出验证结果，覆盖所有核心设计参数的理论值与实际值对比：
- 翼根/翼梢弦长、梢根比
- 半展长、投影面积、展弦比
- 翼根安装角、几何扭转角
- 1/4 弦后掠角、上反角
